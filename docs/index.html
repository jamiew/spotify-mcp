Installation

Published on PyPI — install in one command with uvx. No clone, no local path. 

claude mcp add spotify \
  -e SPOTIFY_CLIENT_ID=your_client_id \
  -e SPOTIFY_CLIENT_SECRET=your_client_secret \
  -e SPOTIFY_REDIRECT_URI=http://127.0.0.1:8888 \
  -- uvx spotify-mcp-jamiew

Works the same in Claude Desktop and Codex — just run uvx spotify-mcp-jamiew.
Requires: Spotify Premium account, uv >= 0.54
